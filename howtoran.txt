How to run eye (Wi-Fi Surveillance & RF Intelligence Platform)
===============================================================

1. Python Wi-Fi Intelligence Server (ai_server)
------------------------------------------------
  cd /home/brown/me/eye
  ai_server/venv/bin/python ai_server/main.py

Health check:
  http://127.0.0.1:8080/health
Night-Vision MJPEG stream:
  http://127.0.0.1:8080/wifi/stream.mjpeg

2. Go Edge Collector (scout) - Optional when using In-App Host Scan / Simulator
-------------------------------------------------------------------------------
Rebuild if modified:
  cd /home/brown/me/eye/scout
  go build -o scout .

Discover available serial / Wi-Fi devices:
  ./scout sources

Stream from auto-detected source (NodeMCU USB -> Host Wi-Fi -> Simulator):
  ./scout detect -source auto -api-url http://127.0.0.1:8080

Stream specifically from plugged NodeMCU USB Serial:
  ./scout detect -source nodemcu -device /dev/ttyUSB0 -api-url http://127.0.0.1:8080

Start bridge listener for unplugged NodeMCU nodes:
  ./scout bridge -listen :8090 -api-url http://127.0.0.1:8080

Run realistic RF scenario simulator:
  ./scout sim -scenario motion -api-url http://127.0.0.1:8080
  # scenarios: mixed, motion, deauth, evil_twin, crowd, congestion, quiet

3. Flutter Night-Vision Control Center (ui)
-------------------------------------------
  cd /home/brown/me/eye/ui
  flutter pub get
  flutter run -d chrome --dart-define=EYE_API_BASE_URL=http://127.0.0.1:8080

4. NodeMCU ESP8266 Flashing (firmware/nodemcu_eye)
--------------------------------------------------
Open firmware/nodemcu_eye/nodemcu_eye.ino in Arduino IDE (NodeMCU 1.0 ESP-12E)
or use PlatformIO (`cd firmware/nodemcu_eye && pio run -t upload`).

When unplugged, hold FLASH (D3/GPIO0) for 2s to start AP "EYE-NODE-SETUP"
and open http://192.168.4.1 to enter your Wi-Fi credentials & server URL.

Verification commands
---------------------
  ai_server/venv/bin/python -m unittest discover -s tests -v
  cd scout && go test -v ./...
  cd ui && flutter analyze && flutter test
